# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este proyecto,
repórtala de forma privada al equipo responsable del repositorio.

No publiques vulnerabilidades de seguridad como issues públicos.

## Versiones compatibles

La versión actual del proyecto es compatible.

## Información que debe incluirse

Incluye:

- Descripción de la vulnerabilidad
- Pasos para reproducirla
- Impacto potencial
- Información adicional que pueda ayudar a investigar el problema
